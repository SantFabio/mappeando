🧪 Como usar o Simulador do Wix

Copie este arquivo para test-sender.html (sem o .example) e adicione os dados dos cursinhos exportados do Wix CMS.

O arquivo test-sender.html está no .gitignore pois contém dados reais.

Estrutura esperada do postMessage:

{
  cursinhos: {
    gratuitos:  [ ...lista de cursinhos gratuitos  ],
    caros:      [ ...lista de cursinhos com bolsa  ],
    acessiveis: [ ...lista de cursinhos acessíveis ]
  },
  filtros: {
    tipoCurso: "checkboxTodos" | "checkboxGratuitos" | "checkboxPagosBolsa" | "checkboxPagosAcessiveis",
    distancia: 10,  // km
    endereco: {
      location: { latitude: -23.5505, longitude: -46.6333 }
    }
  }
}

Campos de cada cursinho:

{
  "_id": "uuid",
  "nome": "Nome do Cursinho",
  "latitude": -23.5505,
  "longitude": -46.6333,
  "enderecoCompleto": "Rua Exemplo, 123",
  "horario": "Seg. a sex. 18h - 22h",
  "telefone": "(11) 99999-9999",
  "email": "contato@cursinho.com",
  "urlSite": "https://...",
  "urlFacebook": "https://...",
  "urlInstagram": "https://...",
  "temProcessoSeletivo": "Sim" | "Não",
  "vagasDisponiveisPresencial": 100,
  "observacoes": "..."
}
